# Contributing

- `make test` runs the 14 pytest checks.
- `make reproduce` regenerates every number, table and figure (~25 min, 4 cores).
- `make cfd` runs the OpenFOAM campaign (~1.5 h, 3 cores).
- Parameters tagged [MS] or [ASM] in src/flockmap/config.py are not measured; do not present them as such.
